## What the student gets
Every course in the list on "Check my courses" now has one answer: it counts toward CIS,
with what it counts as and the standing condition, or it doesn't, with why. Courses that
compete for the same place are sorted out against each other, the legacy question is asked
on the row that needs it, and a reminder appears when the list has no course for the
history or literature sequence.

## User-visible change
Yes.

## What is built
- `src/answers.ts`: one answer per entered course, worked out by placing the typed courses
  with the same code as a transcript (`placeCourses`), so the two flows cannot disagree.
- On the page (`src/check.ts`): the "Does it count?" column with the design's marks (the
  outlined tick for "Counts", the square cross for "Doesn't count") and the tinted,
  heavy-edged row for "Doesn't count"; the two filter buttons "All courses" and "Doesn't
  count"; the reminder note under the list; the legacy question on the rows that need it,
  and a line to change the answer.
- The legacy answer is read from the browser when the app starts, kept in memory for the
  visit and written back when the student answers or changes it (`src/legacy.ts`, F05),
  reaching the browser's storage only through `browserStorage()`.

## How the typed courses are placed
All typed courses are given to `placeCourses` in typed order and in one and the same state
(in progress: courses the student means to take), with the legacy answer as `{ legacy }`.
Because they share a state, the order in a shared place is: the sequence course first,
then typed order; electives in typed order. To find the rows that depend on a legacy
answer not yet given, the list is placed twice, for Yes and for No. (The "third, weaker
state for typed courses" noted in F04's review is not needed without a transcript; it is
carried forward to F12, F14 and F15.)

## The answers (each course gets exactly one)
| When | Answer |
|---|---|
| The course is in a curriculum list and fills a place | "Counts toward CIS — <requirement block>", and under it "unless you've already passed it or filled this slot" |
| It is only an elective by the rule and fills one of the three elective places | "Counts toward CIS: elective (300/400-level <subject>)", with the same condition under it; no title |
| Other typed courses fill the same "pick" | "Doesn't count — it fills the same requirement as <that course>." (for a pick that takes two: "<A> and <B>") |
| The three elective places are filled by earlier typed courses | "Doesn't count — your 3 CIS elective places are already filled by <A>, <B> and <C>." |
| CIS 304 or CIS 415 | "Doesn't count toward CIS — <code> isn't in the current CIS curriculum." |
| Anything else that is in no list and matches no rule | "Doesn't count toward CIS — not in the CIS curriculum" |
| A legacy course, legacy answer Yes, and a place is free | "Counts toward CIS: elective (legacy)", with the same condition under it |
| A legacy course, legacy answer Yes, and no elective place is free | The places-filled sentence above (for PSY 251 kept out by its pick: the same-requirement sentence) |
| A legacy course, legacy answer No | "Doesn't count toward CIS. Legacy students only." |
| A legacy course, no answer yet | The question "Are you a legacy CIS student?" with "Yes" and "No", in place of an answer |

"A legacy course" here is FLS 161, MGT 220 or MGT 203, and PSY 251 when another typed
course is in its Social sciences pick and the legacy answer changes what counts. PSY 251
with its pick to itself is an ordinary course of that block. For a legacy student PSY 251 is placed by the F05 rule. The block
names, the level text (one "N00" for each hundred of the rule's number range, joined by
"/": "300/400-level" for 300 to 499), the "3" and every course code in these sentences
come from the curriculum.

## Decided here (recorded in `docs/decision-log.md`)
- **A row whose answer depends on a legacy answer not yet given shows no verdict.** Besides
  the legacy course itself (which shows the question), another row can depend on it: the
  course sharing PSY 251's pick, or an elective typed after a legacy course when a place
  would be missing. Such a row shows "Answer “Are you a legacy CIS student?” to see this."
  until the question is answered; a row whose sentence is the same for Yes and for No
  shows it straight away. (The waiting sentence is the agent's; listed in the pull
  request.)
- **PSY 251 and the question.** The owner's "when its social-sciences pick is already
  taken" is read as: another typed course is in that pick, in either order, and the answer
  would change what counts. (With the three elective places already full it changes
  nothing, and no question is asked.) PSY 251 alone is not asked about: this
  narrows F05 step 1 for PSY 251 (recorded under the owner's answer; the step's text is
  not changed).
- **PSY 251 with the answer Yes and no place anywhere** (its pick held by a sequence
  course and the three elective places full) shows the same-requirement sentence, which
  names the place the curriculum lists it for.
- **A pick that takes more than one course** names all the courses that fill it, joined
  like the electives sentence ("<A> and <B>"). No such pick is in the CIS curriculum; the
  made-up program has one.
- **Changing the legacy answer.** Once answered, one line under the list says "Legacy CIS
  student: Yes" (or No) with a "Change" button, shown while a course that would show the
  question is in the list (so not for PSY 251 alone); "Change" puts the question back on
  its rows. (Agent's wording; listed in the pull request.)
- **"Counts toward CIS: elective (legacy)" carries the condition** like every "Counts"
  answer without a transcript (step 6).
- **The reminder** is shown when the list has at least one course and none of them is a
  sequence course that sits in a pick (HIS 132, ENG 210). It is not shown for an empty
  list: there is nothing yet to be reminded about.
- **The filter "Doesn't count"** shows only rows whose answer is a "Doesn't count"; rows
  still waiting for the legacy answer are not among them. With nothing to show it says "No
  course in your list is marked “Doesn't count”." (agent's wording; listed in the pull
  request).
- **The summary strip** (total credits, credits that count, credits that don't) is built
  in F09 from these answers; F08 draws no numbers.
- **F08 finishes F07**, and is the first of the three screens that finish F05.
