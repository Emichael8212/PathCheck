# PathCheck
Check whether your courses count toward the Alabama State University B.S. CIS degree before you select them, and see what's left to graduate on time. Independent student project; not affiliated with ASU.

## Keeping the curriculum true
Once a year, and whenever the department changes the B.S. CIS curriculum, the person responsible for PathCheck compares the curriculum and sets the date the pages show. [docs/CURRICULUM-HANDOVER.md](docs/CURRICULUM-HANDOVER.md) says how, step by step, without installing anything.
